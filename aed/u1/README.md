# AED — Unidade 1 (estruturas de domínio em C e Java)

Entrega da AV1 de AED do Projeto Integrador: estoque (lista), requisições (fila),
histórico de operações (pilha) e catálogo de bolsas (ABB), em C com `malloc`/`free`
e reimplementadas em Java no pacote `com.hemorede.estruturas`.

- Documento de tradução comentada C → Java: [`doc/aed-u1-traducao-c-java.md`](../../doc/aed-u1-traducao-c-java.md)
- Código C: [`c/`](c) — `make test`, `make valgrind`, `make run`
- Código Java: [`rotavital/src/main/java/com/hemorede/estruturas`](../../rotavital/src/main/java/com/hemorede/estruturas) — `mvn test -Dtest=EstruturasU1Test`
- Evidências de execução: [`evidencias/`](evidencias)

Fora do escopo desta unidade (fica para a U2): roteirização, FEFO, hash e compatibilidade ABO/Rh.
